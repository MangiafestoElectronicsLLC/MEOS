MEOS Kodi Repository (v1.0.56)

Add this URL as a Kodi File Manager source, then use Install from zip file.

Firestick / Fire TV / Android TV: install Kodi, open the Downloader app and enter this page's URL, or in Kodi use Settings > File manager > Add source with the same URL. Install repository.meos.zip first, then install MEOS Hub from the MEOS Repository (Install from repository > Video add-ons). Works on any device that runs Kodi 18.7 or newer (Windows, macOS, Linux, Android, Fire TV, Raspberry Pi, iOS/tvOS).
